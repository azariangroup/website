# Azarian Inc — Website

Static website for Azarian Inc, a licensed general contractor serving Los Angeles County and Orange County.

## Structure
- `src/pages/` — page sources (edit these)
- `src/partials/` — shared header and footer
- `assets/` — CSS, JavaScript and images
- `*.html` in the root — built pages, ready to deploy

## Editing
Edit files in `src/`, then rebuild the root HTML files:

```sh
sh build.sh
```

Deploy the repository root to any static host (Netlify, Cloudflare Pages, Vercel, GitHub Pages).
